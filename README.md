# FocusList 📝

A clean, responsive, frontend-only To-Do application for managing daily tasks, priorities, and productivity.

## ✨ Features

* ➕ Add new tasks
* ✅ Mark tasks as completed
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* 🔴 High / 🟡 Medium / 🟢 Low task priorities
* 🔍 Search tasks by title
* 📋 Filter by:

  * All
  * Active
  * Completed
* 🎯 Filter tasks by priority
* 📊 Task statistics:

  * Total Tasks
  * Completed Tasks
  * Pending Tasks
* 💾 Persistent data using Browser Local Storage
* 📱 Responsive design for desktop and mobile
* ♿ Accessible interactive controls
* ⚡ Frontend-only — no backend required

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Local Storage
* Responsive Web Design

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/esha-05/focuslist.git
```

### 2. Open the project

```bash
cd focuslist
```

### 3. Run the application

Open `index.html` directly in your browser.

No installation or backend server is required.

## 💾 Data Persistence

FocusList uses the browser's **Local Storage** to save tasks.

Your tasks remain available even after refreshing or reopening the page in the same browser.

## 📱 Responsive Design

The application is designed to work across:

* Mobile
